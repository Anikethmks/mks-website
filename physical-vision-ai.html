Physical AI on the Shop Floor : Automated Pallet Dimensioning for Freight Compliance

MKS deployed an edge computer vision system on existing packaging equipment eliminating manual pallet measurement, reducing freight disputes, and ensuring compliance documentation on every outbound shipment.

Overview The Challenge The Objective The Solution The Impact

Overview

Every outbound pallet needs accurate dimensions and weight it's how freight gets classified correctly and carriers get billed right. For our client, a manufacturer and packager dealing with growing SKU volumes and shipment rates, this was still a manual job. Teams measured pallets by hand, jotted down numbers on paper or typed them into a terminal, and moved on. The result was predictable: measurement errors, disputed freight bills, and documentation that kept falling short.

MKS built a Physical AI solution that fits right into the existing stretch-wrap machine. Now every pallet gets measured automatically as it moves through the packaging line no extra hardware, no cloud required. Freight disputes are down, documentation is right the first time, and the bottleneck that slowed everything down is gone.

The Challenge

Manual pallet dimensioning created compliance risk, billing errors, and a throughput bottleneck at the end of every packaging line

As shipment volumes and SKU complexity grew, the limitations of manual measurement became increasingly costly. Every inaccurate measurement translated directly into either overpayment to carriers or compliance risk with freight classification authorities.

  • Operators measuring stacked pallets by hand introduced systematic measurement variance and human error at scale
  • Manual dimension recording led to frequent freight-fee disputes with carriers, creating invoice reconciliation overhead
  • Shipment documentation regularly failed freight classification requirements, creating compliance exposure on outbound loads
  • The measurement step was a cycle-time bottleneck at the end of the packaging line a manual sub-process inserting delays into an otherwise automated workflow
  • As SKU mix and volume grew, the manual approach simply could not keep pace without proportional headcount increases
  • No consistent audit trail existed linking physical pallet dimensions to shipment records or freight calculations

The Objective

Automate pallet dimensioning inline with the packaging workflow without new infrastructure or cloud dependency

The client needed a solution that worked with what was already on the shop floor. The target was real-time, inline dimension capture with zero manual intervention deployed on existing hardware, running without a network connection, and feeding validated data directly into shipment documentation and freight billing systems.

Capture X, Y, Z pallet dimensions in real time during the wrap cycle

The Solution

Edge AI mounted on existing packaging equipment - measuring every pallet automatically, inline, with no additional infrastructure

MKS deployed a camera hardware on the stretch-wrap machine that every pallet already passes through. A YOLOv8 object detection model runs on-device using the vision processing inference unit - eliminating the need for a separate GPU server on the shop floor. The system captures dimensions in millimetres, streams results to the host device, and pushes validated data directly into downstream freight systems.

  • Every 10 seconds during the wrap cycle, the host triggers the camera to capture a high-resolution image of the stacked pallet
  • A YOLOv8 detection model runs on the on-device - resizing the image to 512×288 for the neural network and returning pallet detections with real-world X, Y, Z coordinates in millimetres via stereo depth estimation
  • Dimension data and RGB metadata stream to the host device; the host renders overlays with OpenCV and converts values to inches for operator familiarity
  • Validated dimensions are logged to local storage and pushed automatically into shipment documentation and the freight-fee calculation engine - closing the loop from physical pallet to compliant paperwork with no manual input
  • The entire solution runs edge-native - no cloud dependency, no external GPU, fully operational on existing hardware across distributed sites

The Impact

Automated measurement, eliminated disputes, and compliance by default - on every outbound pallet

The Physical AI solution transformed pallet dimensioning from a manual, error-prone bottleneck into a real-time, inline operation that operators simply read and confirm. The downstream effects on billing accuracy and compliance were immediate and measurable.
